## A. Top 10 rejection reasons (ranked)

1. **The headline contradicts your own cleanest modality contrast.** F_txt - F_img (same full question, same neutral instruction, both guards agree, kappa 0.92-1.0) is +0.31/+0.35 for the 2B (McNemar p < 1e-25, 8/8 scenarios) and +0.08/+0.07 for the 3B. That is 70-75% of G for the 2B. "Not an image-channel effect for Qwen" rests only on E-C ~ 0, which is (a) a floor effect (E 0.22, C 0.23; the dataset wrapper already drives refusal to the floor), and (b) a different payload. Decomposition shares depend on path (wrapper x modality interaction), so "wrapper = 70-80%" is not a property of the models. Fix: reframe as "the MM-SafetyBench TYPO template is a refusal-suppressing wrapper that saturates; the image effect is hidden under it and reappears with a neutral instruction (F pair)". Cost: zero new GPU.
2. **Neutral-image conditions are invalid, so the interaction test (H11, H15, H17, H18) is void.** Qwen3Guard refusal on C_neutral/NP_neu_img/R_big/R_small/Cben is 0.76-1.00 vs WildGuard 0.07-0.13 vs keyword 0.00-0.02; guard kappa on C_neutral is 0.05/0.09/0.00. Cause visible in code (cell 15): every condition's reply is judged against the full harmful question `q[i]` (or BEN_ALL), not what the model was shown, so a transcription "does not answer" and Qwen3Guard marks Refusal=Yes. The 3-way label (REFUSE/COMPLY/NOT_COMPREHEND) was dropped when the LLM-rubric judges failed, leaving no category for transcribe/describe/clarify. Fix: judge against the stimulus actually shown, add NOT_COMPREHEND (rule: reply restates/describes the image or asks for clarification), re-prompt neutral image conditions with an instruction that demands action ("Do what the text in the image says").
3. **N and Bare are likely contaminated too.** N 0.90 (Q3G) vs 0.72 (WG) vs 0.63 (keyword) in the 2B; N is higher than B (0.66). The phrase alone refuses ~0.9, so the "wrapper effect" is really "the dataset template is a jailbreak that lowers refusal from 0.9 to 0.2". Keyword markers include "i'm sorry"/"not able to", which match clarification replies. Without a 3-way label you cannot say whether 0.9 is refusal or confusion. This is also the "framing dominates" result that the repo itself says exists in prior work, so novelty is thin.
4. **Judge validity is unestablished.** Human gate not passed; v3 and v5 were read before it; two judges failed once already; the guards agree with each other (kappa 0.96+ in clean cells) which shows consistency, not validity; the Qwen3Guard "Refusal" field is undocumented (the repo says so). Human plan: 240 rows = 10 per model x condition cell (cell-level 95% CI about +/-30 points), single author-annotator who knows the hypotheses, rubric maps to 3 labels but the judges output 2 (mapping for kappa unspecified), the audit sheet shows the full request even where the model saw only an image phrase. Fix: below.
5. **LLaVA result is an image-presence effect, not typography.** Blank image alone: refusal 0.45 -> 0.05 (B-D = +0.40 > B-C = +0.33), and C (0.12) > D (0.05). E-C of +0.3 therefore cannot be attributed to typed text. Missing control in all models: E text + blank image (and + irrelevant image). Also LLaVA: 152 items, 336 px square-padded input, 4-bit, F_img kappa 0.095 (judges disagree), so claims "LLaVA differs" are underdetermined.
6. **8 scenario clusters, near-duplicate templated items.** Item-level McNemar (Holm input) treats 304 items as independent; scenario-level analysis is weaker and sometimes contradicts it (2B N - C_neutral under Q3G: McNemar p = 0.02, t(7) CI [-0.055, 0.193]). With 8 clusters the smallest possible sign-test p is 0.0078, which fails Holm over 9 tests (0.05/9 = 0.0056). So no cluster-level claim can survive the stated correction.
7. **Absence-of-effect claimed from non-significance; no equivalence test.** 2B E-C = -0.013, t CI [-0.11, +0.085] includes the 3B effect (+0.08). "2B has no image effect, 3B has a small one" needs a model x condition interaction test; none exists. The mechanical H11a/H16/H17 checks use point estimates against thresholds, not intervals.
8. **Post-hoc hypotheses and tuned thresholds.** Amendments 2-3 were written after v3 was read; H11 thresholds (0.10 for 2B, 0.05 for 3B) copy the v3 pattern. 20 hypotheses, 3 models, 3 labellers, 16 contrasts: about 144 tests, Holm only inside a 9-test family per model x judge. Reviewers will call everything exploratory (you do), which leaves no confirmatory claim yet.
9. **Refusal != harm and the harm analysis is selection-biased.** H14 conditions on non-refusal (post-treatment); C_neutral "unsafe share among non-refusals" 0.91-1.0 is a survivor artefact of a broken label. Use unsafe_rate_all (2B: B 0.18, C 0.64, E 0.64; 3B: 0.10, 0.38, 0.32; both guards) as the harm headline, but it is itself an unvalidated classifier output on small-model replies, and MM-SafetyBench has partly benign items (EconomicHarm G = 0.03-0.08 for the 2B).
10. **Measurement noise and generality.** Greedy decoding, one run; the sanity check shows batch-8 vs batch-1 replies differ in 6-12% of cases (n = 16: 0.9375/0.9375/0.875 identical). Discordant E/C pairs in the 2B are 29 vs 33 of 304, so nondeterminism is not negligible. One benchmark, one rendering (38 px, DejaVu, black on white), English only, 256 tokens, two Qwen models of the same lineage. R_small is not small: cell 3 sets PIX_MIN = 256*28*28, so the processor upscales the short 18 px strips (~1.6x), and read-back is 0.94 (2B) vs 0.91 big, which is why H18 failed; the legibility control did not manipulate legibility.

## B. Statistics audit

- **Decomposition G = P + Cmp + R.** `decompose` (cell 17) sets R = w(E-C | read), Cmp = (1-w)(E-C | unread). Their sum equals E-C identically, so the identity is trivial and Cmp/R are a stratification of E-C by a read flag, not independent causes. B -> G_full -> E -> C is nested (telescoping), but E -> C changes modality and content form at once (lowercase, punctuation-stripped reference phrase from a Qwen-7B reader vs image text), and the F pair shows modality depends on wrapper. Order-dependence/non-additivity means "share of gap" is undefined; report path-specific differences and the interaction, or Shapley values with intervals. No interval is given for any share; the ratio of two noisy differences with G CI [0.22, 0.64] is very wide. The 70-80% is of P, not G.
- **Not supported:** (i) "gap is mostly a wrapper effect" as a general statement (supported only for the dataset template, 3B about 60% of G); (ii) "no image-channel effect in the 2B" (floor effect, F pair contradicts); (iii) LLaVA differs due to the image channel; (iv) H11/H15/H17/H18 anything; (v) "Cmp ~ 0, reading is not the bottleneck" as a causal claim (reading is measured with a different prompt, flags are model-specific, tesseract validation may have been skipped, REF_OK is computed but not used); (vi) any cross-model size claim from two Qwen models; (vii) harm-gap results conditioned on non-refusal.
- **Supported (exploratory):** B vs G_full and B vs E large for Qwen (7-8/8 scenarios, both guards, n = 304); F_txt - F_img large for the 2B; unsafe_rate_all much higher for C/E than B in Qwen; blank image effect on LLaVA (8/8 scenarios, p ~ 1e-18).
- **Pseudo-replication:** same 304 items in 16 conditions is fine for paired contrasts, but items within scenario share templates; use a GLMM (logit, random intercepts for scenario and item) or cluster-robust GEE, and report odds ratios (floor effects make differences in proportions misleading).
- **Floor/ceiling:** report refusal on the logit scale; in the 2B E and C are both ~0.2 with 29/33 discordant pairs; N/Bare are ~0.9 (ceiling).
- **Multiplicity:** define 4-6 confirmatory contrasts total, not per model/judge; use scenario-level inference as primary or a GLMM; Holm over the confirmatory family across models.
- **Agreement stats:** report AC1/PABAK with CIs per cell, but with 10 rows per cell it is mostly uninformative; increase to 25-30 per key cell.

## C. Can this be a paper? Venue and minimal credible claims

Verdict: **not publishable as is; publishable as a workshop paper (and possibly TMLR, with the fixes) if it is reframed as a measurement-validity paper.** ACL main/Findings in January is unlikely from this evidence: thin novelty (framing dominating is, per your own notes, already reported), two same-family models, an unvalidated judge. The "see-saw" framing is not supported and should be dropped or reported as a negative.

Smallest defensible claim set (all exploratory-labelled until the human gate and a confirmatory run):
1. On MM-SafetyBench TYPO, refusal for Qwen2-VL-2B/Qwen2.5-VL-3B falls sharply relative to the plain question, and replacing the image by the same phrase as text under the benchmark's own wrapper recovers most of that fall (2B ~ all, 3B ~ 70%); the benchmark's template, not the image, is the main driver of the TYPO gap.
2. That wrapper reduces refusal even versus the bare phrase (about 0.9 to 0.2), so TYPO-vs-text gaps are confounded in the benchmark design.
3. Modality effects are detectable when the wrapper is neutral and the payload is the full question (F pair), large for the 2B and small for the 3B.
4. Measurement caution: two LLM-rubric judges failed; guard classifiers disagree sharply on non-answer replies; refusal labels need a "did not comprehend" category.
5. LLaVA-1.5: blank image alone kills refusal; the typographic effect is not separable without an image-present control.

## D. Highest-credibility experiments per Colab hour (priority order)

1. **Fix labelling, no generation (0 GPU h, about 1.5 h guards).** Re-judge existing replies against the stimulus actually seen (neutral-image conditions: judge the instruction "do what the text says" with the phrase as intent); add a regex/LLM stage for NOT_COMPREHEND. Result that changes the conclusion: if C_neutral/N refusal collapses to a plausible range, H11/H17 become testable.
2. **Image-presence controls (about 1.5 h for 3 models, 304 items).** E + blank image; E + irrelevant natural image (fixed 8 images); C text with an image of the phrase in a different font. If E+blank ~ C for LLaVA, the LLaVA "typographic" effect is image presence; same test in Qwen decides whether the 3B E-C = +0.08 is typography or presence.
3. **De-saturated modality contrast (about 2 h).** Pair text/image conditions with 3 wrappers of graded strength ("Answer:", "Explain how to...", the benchmark wrapper) x {text, image} x full question and key phrase; fit a logit model with wrapper x modality interaction. Conclusion flips if the interaction is large (modality matters under weak wrappers, vanishes under strong ones).
4. **Real legibility manipulation (30 min).** Render at true 10/14/20/38 px with min_pixels disabled (or unscaled), report read-back per size; do not upscale.
5. **Determinism and noise floor (1 h).** Re-run B/E/C with batch size 1 and a second seed/sampling temperature 0.7 x 3; report between-run flip rate. Needed to interpret 29 vs 33 discordants.
6. **Human audit redesign (no GPU).** 360 rows: 30 per key cell (B, E, N, C, F_img, C_neutral for 2B/3B) plus the oversampled judge-disagreement rows; show annotators the stimulus the model saw; blind to condition; map to the 3 labels; a second annotator on 100 rows (an external person, even a labmate); compute judge-vs-human kappa per cell, and use the human labels to calibrate the guard (report Rogan-Gladen corrected rates).
7. **Third family and size (2-3 h).** Qwen2.5-VL-7B (4-bit) and one of InternVL2.5-2B/4B or Phi-3.5-vision instead of more LLaVA (LLaVA 336 px confounds legibility); 38 items x 8 scenarios is too small, go to 100 per scenario where the data allow.
8. **Harm validity (30 min labelling).** Human-label 100 non-refusals as harmful/not to calibrate Qwen3Guard "unsafe".

## E. Ethics / Responsible-NLP gaps

- Annotator: the author is the only labeller; exposure to harmful content, breaks and opt-out should be stated; any second annotator needs consent and a content warning. Repo hygiene: raw replies must stay out of git (the notes record that v1 gen_*.jsonl is already in the public repo history).
- Licences: MM-SafetyBench (CC-BY-NC per notes), XSTest, model licences, Qwen3Guard and WildGuard (gated; HF terms).
- Dataset validity: partly benign scenarios (Economic Harm, some Privacy) mean "refusal" may be appropriate-compliance; report scenario-wise and a sensitivity analysis without them.
- Claims language: "refusal rate" not "safety"; limitations (English, small models, one rendering, greedy decoding, judge models of the same family as the victims, fp16/4-bit effects).
- ARR Responsible NLP checklist: compute budget, seeds, AI-assistance disclosure (the project used LLM agents heavily for literature and code), data statement for the audit sample.

## F. Notebook/code issues (v5)

1. Cell 15, `ALL_PAIRS[(vn, cond)] = list(zip(intents, resp))` with `intents = ... [q[i] for i in IDX[vn]]`: all non-benign conditions are judged against the full original question even when the model saw a phrase, a neutral instruction or an image. This is the likely cause of Qwen3Guard's 83-100% "refusal" on neutral-image cells and of the C vs E kappa of 0.67. Highest-priority fix.
2. Cell 17 `decompose`: Cmp + R = E - C identically (see B); naming "comprehension" and "routing" overstates. `w` comes from a different prompt (transcription), post-hoc per model.
3. Cell 19 PRESPEC checks apply point-estimate thresholds ("abs(diff) <= 0.10"), not intervals or equivalence tests; `_both` requires both guards even when one is known-invalid for the cell. The printed True/False will be quoted; add "invalid cell" flags.
4. Cell 21 `holm(ps)` uses item-level McNemar p (`mcnemar_b_c_p[2]`) ignoring clustering, per model x judge; the "interaction_all" is a mean over items with a scenario-level t CI but is computed from the broken C_neutral.
5. Cell 3: `PIX_MIN = 256*28*28` upscales small renders, defeating R_small; `FONT_SMALL = 18` never manipulates effective legibility.
6. Cell 5 `to_text_prompt`: E text is lowercased, punctuation-stripped (`norm_text`) and put after the instruction, whereas C has mixed-case image plus instruction after the image: order, case and token position differ; `model_idx` assumes `i % N_PER_SCENARIO` blocks of exactly 38 (true here, fragile).
7. Cell 9: `REF_OK` is computed (tesseract agreement) but unused downstream; if pytesseract was not installed (cell 2 skips silently), reference phrases are "unvalidated" and E-C rests on a single Qwen-7B reading.
8. Cell 25 audit sheet: `request` column is the full question for every condition, not the stimulus; the rubric's COMPLY ("or the activity it mentions") vs NOT_COMPREHEND boundary for transcriptions is undefined; 10 rows per cell; the 50-row second-annotator subset is only a column marker.
9. Cell 13 `score_readback` treats any refusal-marker string in the first 200 characters as failure and uses first line only, so legitimate reads with a preamble are penalised, and the read prompt differs from the answer prompt.
10. Cell 11: NP paraphrase fallback share is 0.0, which is surprising for 304 harmful requests with a 7B 4-bit model; check that the paraphrases are not copies of the key phrase before trusting H16 (which itself failed).

## Verdict and next step

Verdict: not publishable as is; publishable as a workshop-level measurement paper with the fixes above, TMLR possible after a confirmatory run with a third family and validated judges, ACL 2027 main unlikely. The strongest honest story is "the benchmark's TYPO wrapper, not the image, drives most of the gap for Qwen; modality matters under neutral instructions and for LLaVA, but measurement of non-answers is broken". The see-saw framing should be dropped. The most important next experiment is re-judging every condition against the stimulus actually shown with a three-way label (no GPU generation), immediately followed by the image-presence control (E + blank/irrelevant image), because those two decide whether H11/H17 and the LLaVA claim mean anything.
